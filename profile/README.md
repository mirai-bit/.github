## 日本語

ミライビットは、Physical AI の研究開発を行う東京のスタートアップです（2024年10月設立、東京都中央区）。ロボットが視覚や言語の指示をもとに、現実の環境で自ら作業を実行できる技術の実現を目指しています。

AIモデルの開発だけでなく、実際のロボットを動かしてデータを集め、学習・評価し、再度実機で検証する——このサイクルを自社ラボで完結させています。

### 研究開発

- オープンソースの双腕ロボット **OpenArm v2** を用いた遠隔操作・データ収集環境の構築
- **Unitree G1** ヒューマノイドへの展開を含むロボット操作 AI（VLA: Vision-Language-Action）の研究開発

### 事業内容

## English

mirai-bit Inc. is a Tokyo-based startup (founded October 2024) researching Physical AI — robots that carry out manipulation tasks in the real world from visual and language instructions.

Beyond model development, we run the full loop in-house: operating real robots to collect data, training and evaluating models, and validating the results back on real hardware.

### R&D

- Teleoperation and real-robot data collection environments built on the open-source dual-arm robot **OpenArm v2**
- Vision-Language-Action (VLA) manipulation research, extending to the **Unitree G1** humanoid

### Services

- Support for building real-robot data collection environments
- Contracted R&D and PoC on Physical AI
